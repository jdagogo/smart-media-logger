## Episode/Segment Formats

### By Length
- **Standard Episode**: 22-24 min (broadcast half-hour)
- **Extended Standard**: 30 min (streaming half-hour)
- **Hour Episode**: 42-48 min (broadcast hour)
- **Extended Hour**: 55-65 min (streaming hour)
- **Short-Form**: 5-15 min
- **Micro-Content**: < 5 min
- **Super-Sized**: 75+ min (special episodes)

### By Structure
- **Serialized**: Continuous story across episodes
- **Procedural**: Self-contained episodes
- **Hybrid**: A-plot procedural, B-plot serialized
- **Anthology Episode**: Standalone story/cast
- **Bottle Episode**: Limited location/cast (budget)
- **Flashback Episode**: Past timeline
- **Flash-Forward Episode**: Future timeline
- **Clip Show**: Compilation of previous footage
- **Crossover Episode**: Characters from other series

### By Position
- **Pilot**: First episode
- **Series Premiere**: First episode of series
- **Season Premiere**: First episode of season
- **Mid-Season Premiere**: Return from break
- **Season Finale**: Last episode of season
- **Series Finale**: Final episode ever
- **Special Episode**: Holiday, event, milestone

## Music & Soundtrack

### Series-Level Music
- Main Theme
- Composer
- Music Supervisor
- Score Album(s)

### Episode-Level Soundtrack

**This is the key differentiator from film.**

| Field | Description | Source |
|-------|-------------|--------|
| Song Title | Name of licensed song | Soundtracki, NME, Tunefind |
| Artist | Performer | Same |
| Timestamp | When in episode (e.g., "0:23") | Soundtracki |
| Scene Description | Context for song placement | Recap sites |
| YouTube URL | Link to song | Constructed search |
| Spotify URL | Link to song | API lookup |

### Example: Pluribus Episode 3
```json
{
  "episode": 3,
  "title": "Grenade",
  "soundtrack": [
    {
      "position": 1,
      "title": "Cogito",
      "artist": "Akusmi",
      "timestamp": "",
      "scene": "",
      "youtubeSearchUrl": "https://youtube.com/results?search_query=..."
    },
    {
      "position": 2,
      "title": "The Sweetest Taboo",
      "artist": "Sade",
      "timestamp": "",
      "scene": "Carol and Helen flashback",
      "youtubeSearchUrl": "..."
    },
    {
      "position": 3,
      "title": "Sonnet",
      "artist": "DakhaBrakha",
      "timestamp": "",
      "scene": "End credits",
      "youtubeSearchUrl": "..."
    }
  ]
}
```

### Soundtrack Data Sources

| Source | Accessibility | Data Quality | Coverage |
|--------|--------------|--------------|----------|
| **Soundtracki** | Scrapable | Episode-level, timestamps | Older shows |
| **NME** | Scrapable | Episode-level, no timestamps | Popular shows |
| **Tunefind** | Blocked (403) | Best - scene descriptions | Comprehensive |
| **WhatSong** | Blocked (403) | Good | Comprehensive |
| **Wikipedia** | Blocked (403) | Basic | Limited |

## Music Streaming Platforms

Once we identify songs from an episode, we need to link to where users can actually listen. These platforms also provide rich metadata we should capture.

---

### Spotify ✅

| | |
|-|-|
| **API URL** | api.spotify.com/v1/ |
| **Access** | ✅ Free with OAuth (Client Credentials flow for search) |
| **Rate Limit** | ~180 requests/minute |
| **Documentation** | developer.spotify.com/documentation/web-api |

#### Track Metadata
- Track ID, name, duration (ms)
- Artist(s) with IDs
- Album name, ID, release date
- Album art (multiple sizes: 64, 300, 640px)
- Explicit flag
- Popularity score (0-100)
- Preview URL (30-second clip)
- ISRC (International Standard Recording Code)
- Track number, disc number
- Available markets (countries)
- External URLs (Spotify link)

#### Audio Features (per track)
- **Tempo** (BPM)
- **Key** (0-11 representing C through B)
- **Mode** (major/minor)
- **Energy** (0.0-1.0)
- **Danceability** (0.0-1.0)
- **Valence** (0.0-1.0, musical positivity)
- **Acousticness** (0.0-1.0)
- **Instrumentalness** (0.0-1.0)
- **Liveness** (0.0-1.0)
- **Speechiness** (0.0-1.0)
- **Loudness** (dB)
- **Time signature**

#### Artist Metadata
- Artist ID, name
- Genres (array)
- Popularity (0-100)
- Follower count
- Images (multiple sizes)
- External URLs

#### Album Metadata
- Album ID, name, type (album/single/compilation)
- Release date, precision (year/month/day)
- Total tracks
- Label
- Copyrights
- Album art (multiple sizes)
- Artists
- Available markets

#### Official TV Show Playlists
Many shows maintain official Spotify playlists:

| Show | Playlist | Curator |
|------|----------|---------|
| Succession | "Succession (HBO)" | HBO |
| Stranger Things | "Stranger Things" | Netflix |
| Euphoria | "Euphoria" | HBO |
| The Bear | "The Bear" | FX/Hulu |
| Wednesday | "Wednesday" | Netflix |

**Finding Official Playlists:**

**Network/Platform Spotify Accounts:**
- HBO: `haborecords`
- Netflix: `netflix`
- Amazon Prime: `amazonmusic`
- Apple TV+: `applemusic`
- Showtime: `showtime`

#### Score/Soundtrack Albums
- Official Score albums (composer releases)
- Official Soundtrack compilations
- "Music From" albums

**Search patterns:**
```
GET /search?q=pluribus%20soundtrack&type=album
GET /search?q=succession%20score%20nicholas%20britell&type=album
GET /search?q=stranger%20things%20volume&type=album
```

#### API Endpoints
```
# Search
GET /search?q={query}&type=track,album,playlist,artist

# Track data
GET /tracks/{id}
GET /tracks?ids={id1,id2,id3}           # Batch (max 50)
GET /audio-features/{id}
GET /audio-features?ids={id1,id2}       # Batch (max 100)

# Artist data
GET /artists/{id}
GET /artists/{id}/albums
GET /artists/{id}/top-tracks?market={country}
GET /artists/{id}/related-artists

# Album data
GET /albums/{id}
GET /albums/{id}/tracks

# Playlist data
GET /playlists/{id}
GET /playlists/{id}/tracks
GET /users/{user_id}/playlists

# Browse (curated content)
GET /browse/categories
GET /browse/categories/{category_id}/playlists
GET /browse/new-releases
```

```

```

#### Constructing Search URLs
When we can't use the API (quota limits):
```
# Direct search URL

# Music-filtered search
https://music.youtube.com/search?q={song}+{artist}

# Playlist search
```

### ISRC (International Standard Recording Code)
- Universal identifier for recordings
- Format: CC-XXX-YY-NNNNN (country, registrant, year, designation)
- Same song, different recording = different ISRC
- Use for cross-platform matching

### Cross-Platform ID Mapping

To link the same song across platforms:

1. **Search by ISRC** (most reliable)
   - Spotify: `GET /search?q=isrc:{code}&type=track`
   - Apple Music: Include ISRC in search

2. **Search by title + artist** (fallback)
   - Normalize strings (lowercase, remove punctuation)
   - Handle featuring artists
   - Handle remixes vs originals

3. **Use MusicBrainz** as intermediary
   - Open database linking all platforms
   - Maps ISRCs to platform IDs

### Official Playlist Discovery Strategy

```
1. Search Spotify for "{show name}" playlists
2. Filter by verified/official accounts (HBO, Netflix, etc.)
3. Check playlist description for "official" language
4. Verify curator is network/platform account
5. Cache playlist ID for future episode lookups
6. Poll for updates (new episodes = new songs added)
```

### Score vs "Music From" - Critical Distinction

This is one of the most important distinctions in TV music metadata. They are fundamentally different:

---

#### Original Score

**Definition:** Instrumental music composed specifically for the show by a hired composer.

| Attribute | Description |
|-----------|-------------|
| **Creator** | Composer (hired by production) |
| **Ownership** | Usually owned by production company |
| **Purpose** | Underscore, themes, emotional cues |
| **Release** | "Original Score" or "Original Television Soundtrack" albums |
| **Credits** | Composer, orchestrator, music editor |

**Characteristics:**
- Written specifically for scenes
- Thematic (character themes, location themes)
- Instrumental (usually no vocals)
- Builds tension, emotion, atmosphere
- Often unreleased or partially released
- Composer retains some rights for album release

**Finding Score Albums:**
```
Search: "{show} original score"
Search: "{show} original television soundtrack"
Search: "{composer name} {show}"
```

**Example - Pluribus:**
| | |
|-|-|
| **Composer** | Dave Porter |
| **Previous Work** | Breaking Bad, Better Call Saul |
| **Style** | Electronic, atmospheric, tension-building |
| **Album** | "Pluribus: Original Score from the Apple TV+ Series" |
| **Where to Find** | Spotify, Apple Music, Bandcamp (often composer's page) |

**Example - Succession:**
| | |
|-|-|
| **Composer** | Nicholas Britell |
| **Style** | Hip-hop influenced classical, piano-driven |
| **Albums** | "Succession: Season 1-4" (multiple score albums) |
| **Notable** | Emmy-winning, commercially successful |

---

#### Licensed Music / "Music From"

**Definition:** Pre-existing songs licensed for use in the show by a music supervisor.

| Attribute | Description |
|-----------|-------------|
| **Creator** | Original artist (not affiliated with show) |
| **Ownership** | Artist/label owns; show pays licensing fee |
| **Purpose** | Needle drops, source music, montages |
| **Release** | "Music From" compilations, or individual tracks |
| **Credits** | Music Supervisor selects and clears rights |

**Characteristics:**
- Pre-existing recordings
- Licensed (paid sync fee + master fee)
- Often recognizable songs
- Selected by Music Supervisor
- May be diegetic (character hears it) or non-diegetic

**Finding Licensed Music:**
```
Search: "{show} music from"
Search: "{show} soundtrack" (often means licensed music)
Search: "{show} songs"
Sources: Soundtracki, Tunefind, NME
```

**Example - Pluribus:**
| | |
|-|-|
| **Music Supervisor** | Thomas Golubić |
| **Previous Work** | Breaking Bad, Better Call Saul, The Walking Dead |
| **Style** | Eclectic, often unexpected choices |
| **Notable Tracks** | "The Sweetest Taboo" (Sade), "Cogito" (Akusmi) |
| **Where to Find** | Soundtracki, episode-by-episode listings |

**Example - Succession:**
| | |
|-|-|
| **Music Supervisor** | Rob Lowry |
| **Notable Tracks** | "L to the OG" (in-show), various classical, hip-hop |

---

#### Terminology Guide

| Term | Meaning | Album Title Pattern |
|------|---------|---------------------|
| **Original Score** | Composer's work for the show | "{Show}: Original Score" |
| **Original Television Soundtrack** | Usually means score | "{Show}: Original Television Soundtrack" |
| **Music From** | Licensed songs compilation | "Music From {Show}" |
| **Soundtrack** | Ambiguous - could be either | "{Show} Soundtrack" |
| **Songs From** | Licensed music | "Songs From {Show}" |
| **Inspired By** | Songs thematically related (not in show) | "Music Inspired By {Show}" |

**Warning:** "Soundtrack" is often used loosely. Always check contents:
- If it's all one artist (the composer) → Score
- If it's various artists → Licensed music compilation
- If it's mixed → Combined release

### Recommended Fetch Order

For comprehensive episode data:

```
1. TMDB API
   → Series info, season/episode structure, basic cast

2. IMDB Scrape (if needed)
   → Detailed cast per episode, guest stars, ratings

3. Soundtracki + NME
   → Episode soundtrack with fallback

4. Esquire / Autostraddle
   → Plot summary, themes, analysis

5. Hollywood Life / EPGuides
   → Cast backgrounds, air dates
```

---

### Known Limitations

1. **No single source has everything** - must aggregate from multiple sources
2. **Newer shows** often missing from Soundtracki (use NME/web search)
3. **Guest cast** best from IMDB episode pages, not TMDB
4. **Scene-level soundtrack timestamps** only from Soundtracki (when available)
5. **Deep analysis** requires recap sites, not available via API
6. **Best sources blocked** - Vulture, Tunefind, Wikipedia all return 403

## Logging Workflow Differences from Film

### What's Different
1. **Granularity** - Can log at series, season, or episode level
2. **Progress Tracking** - "Currently Watching" status needed
3. **Binge Sessions** - Multiple episodes in one sitting
4. **Episode Ratings** - May want to rate individual episodes
5. **Discovery per Episode** - Songs discovered from specific episodes

### Logging Options
1. **Log Episode** - Single episode watched
2. **Log Binge** - Multiple episodes (date range or list)
3. **Log Season** - Finished a season
4. **Log Series** - Completed entire series

### Questions to Ask (Episode Log)
- Which episode?
- When did you watch?
- Where did you watch? (home, travel, etc.)
- Rating (1-100)?
- Standout moment?
- Notes?
- Any songs you want to save?
