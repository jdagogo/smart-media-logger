Known Issues & Limitations

Critical Issues

  • Entity recognition is poor - Fails to recognize many actors, directors, musicians even with fuzzy matching
  • Date handling bugs - Dates sometimes display incorrectly (wrong year, wrong day)
  • Duplicate entries - Completing a log sometimes creates duplicate entries in My Stuff

Moderate Issues

  • Voice input inconsistent - Web Speech API sometimes drops words or fails silently
  • State management fragile - Complex prop drilling between page.tsx and RightPaneTabs
  • No real AI integration - Uses hardcoded questions, not Claude API as intended
  • Data not persisted - All data is in-memory, lost on refresh
The "Smart" in Smart Media Logger:
Currently this app is more "dumb" than "smart". The AI-powered features (intelligent question generation, discovery moments, personalized recommendations) are not yet implemented. What exists is a basic logging flow with some entity highlighting.
