Known Issues & Limitations

Critical Issues

  • Entity recognition is poor - Fails to recognize many actors, directors, musicians even with fuzzy matching
  • Date handling bugs - Dates sometimes display incorrectly (wrong year, wrong day)
  • Duplicate entries - Completing a log sometimes creates duplicate entries in My Stuff

Moderate Issues

  • Voice input inconsistent - Web Speech API sometimes drops words or fails silently
  • State management fragile - Complex prop drilling between page.tsx and RightPaneTabs
  • No real AI integration - Uses hardcoded questions, not Claude API as intended
  • Data not persisted - All data is in-memory, lost on refresh
The "Smart" in Smart Media Logger:
Currently this app is more "dumb" than "smart". The AI-powered features (intelligent question generation, discovery moments, personalized recommendations) are not yet implemented. What exists is a basic logging flow with some entity highlighting.

TV/Streaming Module (Pluribus):
TV and streaming media will need a different logging workflow than movies. Consider: episode vs season vs series logging, binge sessions, "currently watching" status, progress tracking, and streaming platform integration. Will require new data models for Series → Season → Episode hierarchy.
TV Episode Soundtrack API (POC Built):
Prototype API at /api/tv-soundtrack scrapes Soundtracki.com for episode-level soundtrack data. Returns: song title, artist, timestamp, scene description, YouTube search URL. Tested with Succession S4E10 - successfully retrieved Leonard Cohen, Nicholas Britell score cues with scene context. Needs: cleaner HTML parsing, episode boundary detection, result caching, UI for show → season → episode selection.
CRITICAL: Data Persistence
Currently all data is stored in React state (memory) and localStorage. This means: data is lost on refresh (state), limited to ~5MB (localStorage), no cross-device sync, no backup/restore. Phase 2 MUST implement proper database persistence (Prisma + SQLite already scaffolded but unused).
My Media Model - Auto-Analyze Notes:
User notes should be automatically analyzed to extract entities (people, themes, places, emotions) and feed into My Media Model. Currently notes are just stored as plain text with no AI processing.
YouTube & Playlist Caching:
Currently every soundtrack search hits the YouTube API fresh. Need to: (1) Cache playlist search results and track listings, (2) Persist manually-edited playlist overrides properly, (3) Reduce API calls to avoid rate limits. Reference the caching system in YouTube Analysis app (port 3002) for implementation patterns.
Clickable Talent Discovery:
Make artist/director/talent names clickable to discover more of their work. For music: click "Johnny Greenwood" or "Elton John" to see a list of their songs you can heart and add. For movies: click director name to browse their filmography. Eventually extend to all talent (actors, composers, etc.). Requires API integration to fetch filmographies/discographies.
My Media Model Redesign:
Completely redesign My Media Model to be more visual, comprehensive, and useful. Current version is basic text-based analysis. Needs: visual data representations (charts, graphs, word clouds), deeper pattern recognition, better entity relationships, timeline views, taste evolution tracking, and actionable insights. Should feel like a personalized media dashboard.
Upcoming Film Reminders:
For films added to queue that aren't released yet, capture the release date and notify user when it's approaching. Show "Coming Soon" badge on queued items with release dates. Send reminder notifications (email, push, or in-app) a week before and on release day. Essential for tracking anticipated films discovered via trailers.
Browser Extension for Smart Capture:
Chrome/Safari extension that captures movie data from any page (A24, IMDb, Letterboxd, RT). Extracts title, cast, crew, trailer, release date - even for films not yet in TMDB. Sends directly to Smart Media Logger queue. Solves the "upcoming film" problem where TMDB doesn't have the movie yet but distributor sites do.
