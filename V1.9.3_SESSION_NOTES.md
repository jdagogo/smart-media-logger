# v1.9.3-alpha Session Notes

## Date: January 11, 2026

## Overview
This was an all-day debugging session to fix data persistence issues for movie metadata. The core problem was that metadata fields (officialWebsite, distributor, releaseDate, metacriticUrl, rottenTomatoesUrl, imdbId) would show correctly in the preview but **disappear when saving to queue or logging**.

---

## Problems Fixed (In Order of Discovery)

### Problem 1: Hardcoded Data for Unreleased Films
**Issue:** "Undertone" and "The Moment" are upcoming A24 films not yet in TMDB. When pasting their trailer URLs, wrong data was returned.

**Solution:** Added `HARDCODED_MOVIES` object in `youtube-metadata/route.ts` with complete metadata for these films, including:
- Title, year, overview, poster
- Director, writers, composer, cast
- Genres, runtime, rated
- Distributor, officialWebsite, releaseDate
- IMDB ID and URL
- Metacritic/RT URLs (even without scores)

**File:** `src/app/api/youtube-metadata/route.ts` (lines 6-95)

### Problem 6: Wrong A24 Link (Linking to YouTube)
**Issue:** User said "I give you the A24 link and you put in the wrong link. You put in a link to YouTube."

**Root Cause:** Confusion between DETECTION source and LINK destination.

**Key Understanding:**
- **Detection sources:** YouTube title ending with "| A24", YouTube channel name, TMDB production_companies
- **Link destination:** ALWAYS `https://a24films.com/films/{slug}`, NEVER YouTube

**Solution:** Updated A24 detection logic:
```typescript
const isA24 =
  tmdbData.distributor === 'A24' ||
  metadata.production === 'A24' ||
  (metadata.title && /\|\s*A24\s*$/i.test(metadata.title)) ||
  (metadata.author && metadata.author === 'A24')

if (isA24) {
  const titleSlug = tmdbData.title.toLowerCase().replace(/[^a-z0-9\s-]/g, '').replace(/\s+/g, '-')
  metadata.officialWebsite = `https://a24films.com/films/${titleSlug}`
  metadata.distributor = 'A24'
}
```
**File:** `src/app/api/youtube-metadata/route.ts` (lines 304-329)

### Problem 10: TMDB Distributor Detection Failing
**Issue:** `tmdbData.distributor` was always undefined because fetchTMDBData wasn't returning it.

**Solution:** Added production company extraction and distributor detection to fetchTMDBData:
```typescript
const productionCompanies = details.production_companies?.map((c: any) => c.name) || []
let distributor: string | undefined
if (productionCompanies.some((c: string) => c === 'A24')) {
  distributor = 'A24'
} else if (productionCompanies.some((c: string) => c.includes('Searchlight'))) {
  distributor = 'Searchlight Pictures'
}
// etc.
```

**Note:** For Lady Bird, A24 wasn't in TMDB's production_companies (they were distributor, not producer). Detection now also checks YouTube title/channel.

---

### Problem 11: Foreign Film Title Extraction Failing
**Issue:** "Capernaum | Official US Trailer HD (2018)" was extracting as "Capernaum | Official US" instead of just "Capernaum".

**Root Cause:** Regex didn't handle "Official US Trailer" format.

**Solution:** Updated regex to be more flexible:
```typescript
// Handle "| Official US Trailer", "| Official Trailer", "| Trailer", etc.
.replace(/\s*[\|\-–][^|\-–]*Trailer.*$/i, '')
```
**File:** `src/app/api/youtube-metadata/route.ts` (line 480)

## Data Flow Checklist

When adding new metadata fields, ALL of these must be updated:

1. ☐ API response returns the field
2. ☐ urlMetadata state type includes field
3. ☐ setUrlMetadata call copies field from API response
4. ☐ addToQueue copies field to newItem object
5. ☐ addToQueue copies field to previewData object
6. ☐ newLoggedItem copies field (BOTH instances in page.tsx)
7. ☐ logData → currentEntry includes field
8. ☐ currentEntry → MediaCard props includes field
9. ☐ QueueItem interface includes field
10. ☐ LoggedItem interface includes field

## Lessons Learned

1. **Data flows through MANY places** - When adding a new field, it must be added to 8+ locations
2. **Detection ≠ Linking** - YouTube channel can be used to DETECT distributor, but link should go to official site
3. **OMDB has limited data** - Use IMDB scraping for box office (domestic + worldwide)
4. **TMDB production_companies ≠ distributors** - A24 may not be in production_companies even for A24 films
5. **Title extraction is fragile** - Many trailer title formats exist (Official US Trailer, Official Trailer HD, etc.)
6. **Hardcode unreleased films** - Films not in TMDB need hardcoded data to avoid wrong lookups
